# BA STORE - ระบบบอกเรทราคาขายปลีก & ระบบจัดการหลังบ้าน (Admin System)

ระบบแสดงเรทราคาขายปลีกสำหรับร้านจำหน่ายแอพพรีเมียม ถอดแบบสไตล์สวยงาม โทนสีชมพูพาสเทลน่ารักจากต้นแบบ [ba-store-ten.vercel.app](https://ba-store-ten.vercel.app/) พร้อมตัดระบบ OTP ออกอย่างสมบูรณ์ และเพิ่มระบบจัดการหลังบ้าน (Admin Dashboard) ที่สามารถ **เพิ่ม ลบ แก้ไข** ข้อมูลสินค้า เรทราคา โปรโมชั่น และข้อมูลร้านค้าได้สะดวกรวดเร็ว เชื่อมต่อฐานข้อมูล Supabase แบบ Realtime

---

## 🌟 ฟีเจอร์เด่นของระบบ

1. **ถอดระบบ OTP ออกทั้งหมด**:
   - ไม่มีปุ่ม "รับรหัส OTP" และตัดสินค้าหมวด OTP ออกจากระบบเรียบร้อย
   - เน้นปุ่ม "ติดต่อสั่งซื้อทาง LINE" ให้โดดเด่น กดแล้วส่งข้อความสั่งซื้อที่ระบุชื่อแอพและราคาพร้อมคุยทันที
2. **ใช้ภาพจริงของแอพ (Authentic Real Logos)**:
   - ใช้ภาพโลโก้ของแท้จากแอพยอดนิยม: Netflix, YouTube, Disney+, Viu, iQIYI, WeTV, Bilibili, Spotify, Canva, ChatGPT, CapCut, Youku
   - มีคลังรูปภาพโลโก้จริงให้คลิกเลือกได้ทันทีตอนเพิ่ม/แก้ไขสินค้า หรือเลือกอัปโหลดรูปจากเครื่อง/ใส่ URL ก็ได้
3. **ระบบจัดการหลังบ้าน (Admin System)**:
   - เข้าสู่ระบบด้วยรหัส PIN (ค่าเริ่มต้นคือ `1234` ปรับเปลี่ยนได้ที่หน้าตั้งค่า)
   - **เพิ่ม ลบ แก้ไข** รายการแอพ สเปกอุปกรณ์ ความคมชัด และรายละเอียด
   - รองรับการตั้งราคาแบบหลายระดับ (Multi-tier Pricing) เช่น เมลล์ลูกค้า, เมลล์ร้าน, ราย 7 วัน, 30 วัน, 90 วัน
   - ปรับสถานะสินค้า (พร้อมส่ง / รอกด / สินค้าหมด) ได้ในคลิกเดียว
   - จัดการโปรโมชั่นพิเศษแพ็กคู่ (Hot Deals Combos)
   - ปรับแต่งข้อมูลร้านค้า: แบนเนอร์, โลโก้, ชื่อร้าน, คำโปรย, ประกาศวิ่ง, เวลาทำการ, ลิงก์ LINE
4. **ฐานข้อมูล Supabase + Realtime Sync**:
   - รองรับการเชื่อมต่อกับ Supabase สำหรับจัดเก็บข้อมูลบน Cloud
   - ซิงค์ข้อมูล Realtime (`postgres_changes`): เมื่อแอดมินแก้ไขราคา ทุกคนที่เปิดเว็บอยู่จะเห็นราคาใหม่อัปเดตทันทีแบบสดๆ
   - ความปลอดภัยสูง: ใช้เฉพาะ Anon Key ผ่าน `.env` หรือตั้งค่าหลังบ้าน (ไม่แสดง Service Role Key หรือความลับบนหน้าเว็บ)
   - ออฟไลน์เฟิร์ส (Offline First): มี LocalStorage แคชคู่ขนาน ใช้งานได้ทันทีแม้ยังไม่ได้เชื่อมต่อฐานข้อมูล
   - มีปุ่มสำรองข้อมูล (Export JSON) และกู้คืนข้อมูล (Import JSON)

## 🚀 วิธีเปิดใช้งานระบบ (Quick Start)

### 1. เริ่มรันโปรเจกต์
```bash
# ติดตั้ง dependencies (หากยังไม่ได้ติดตั้ง)
npm install

# รันระบบ Development Server
npm run dev
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:5173/`

## 🗄️ การตั้งค่าฐานข้อมูล Supabase (Database Setup)

1. ไปที่ [Supabase](https://supabase.com/) แล้วสร้างโปรเจกต์ใหม่ (หรือใช้โปรเจกต์เดิมที่มีอยู่)
2. ไปที่เมนู **SQL Editor** -> กด **New Query**
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `supabase_schema.sql` ในโฟลเดอร์นี้ ไปวางในช่อง Query แล้วกด **Run**
4. ไปที่ **Project Settings** -> **API**
   - คัดลอก **Project URL**
   - คัดลอก **Project API Keys (anon public)**
5. นำค่าที่ได้มาใส่ในไฟล์ `.env`:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```
   *(หรือสามารถล็อกอินเข้าหลังบ้าน Admin แล้วกรอกในแท็บ "ฐานข้อมูล Supabase" ได้เช่นกัน)*

## 🔑 ข้อมูลการเข้าสู่ระบบหลังบ้าน (Admin Access)

- กดที่ปุ่ม **"เข้าสู่ระบบหลังบ้าน (Admin)"** ที่มุมล่างขวาของหน้าเว็บ (ในส่วน Footer)
- รหัส PIN เริ่มต้น: `1234`
- เมื่อล็อกอินแล้ว จะมีแถบควบคุมของ Admin ปรากฏขึ้นมา สามารถคลิกแก้ไข ลบ หรือเปลี่ยนสถานะสินค้าได้ทันที
- สามารถเปลี่ยนรหัส PIN ได้ที่เมนู **"ตั้งค่าร้านค้า & Supabase"**
